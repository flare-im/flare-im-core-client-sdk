消息操作原型

桌面 hover/right-click；移动 long press/sheet
发送链路

输入 -> optimistic row -> sending -> sent/delivered/read -> failed 保留原气泡并提供重试。

引用回复

消息菜单选择回复 -> composer 顶部引用条 -> 发送后 quote strip 可定位原消息。

多选批量

进入多选 -> checkbox 稳定占位 -> 底部工具栏：转发、删除、收藏、取消。

媒体处理

上传进度在媒体上层；下载状态在 hover/菜单内；Tauri 可打开所在文件夹。

插件消息

支持任务、日程、投票、公告、自定义；插件不可用时显示 typed fallback。

搜索定位

搜索结果点击 -> 加载上下文 -> 保持滚动锚点 -> 高亮目标消息 1.6 秒。

状态异常

断线、重连、同步失败分别进入 header strip、composer hint、empty/error state。

未知符号

表情包 token 未解析时显示可读标签和缺失资源提示，不裸露乱码。

消息类型展示矩阵

所有类型都必须可读、可恢复、可降级
文本

CJK、URL、emoji、code 自动换行。

富文本

块级结构、引用、列表、mention。

图片/图片组

稳定比例、预览、下载、时间状态。

视频/音频

播放控件、时长、进度和上传态。

文件

图标、名称、大小、下载/打开。

位置

地图缩略、地址、打开操作。

引用/转发

来源、摘要、点击定位或展开。

表情/贴纸

优先资产，缺失时可读 fallback。

系统通知

居中、弱化、无多余操作。

插件卡片

任务、日程、投票、公告、自定义。

核心约束：任何内容都不能挤压输入器、覆盖菜单、溢出气泡或在失败后消失。失败消息保留稳定身份，直到用户重试成功或显式删除。
