消息展示设计

内容类型、状态和 fallback 一屏可评审
文本 / 富文本
支持中文、English、长链接、inline code、@成员，高亮但不破坏换行。
引用 / 转发
引用条显示发送者和摘要；转发卡显示来源、数量和展开入口。
图片 / 视频
预览稳定比例；上传/下载/打开所在位置都有明确状态。
音频 / 文件
音频波形与时长；文件名、大小、下载进度和失败重试。
位置 / 链接
地图缩略、地址；链接卡显示域名、标题、缩略图 fallback。
表情包 / 贴纸
优先渲染资产；未知 token 显示“未安装表情”，避免乱码或原始符号外露。
插件卡片
任务、日程、投票、公告、自定义消息同一插件卡片骨架。
失败 / 撤回
失败消息保留气泡和稳定 key；撤回消息弱化显示，不提供无效操作。
